## 产品边界

| 项目 | 仓库 | 职责 |
| --- | --- | --- |
| XLaunch | ai-workspace-lab/XLaunch | 分类、应用搜索、系统动作、自然语言 Agent Command |
| XDock | ai-workspace-lab/XDock | 固定应用、运行指示、打开应用、激活及切换窗口 |

XDock 是桌面 Dock，不是 Docker 容器管理工具。两个产品无强制运行时依赖，可以各自发布。当前仅提供设计说明，未复制 XLaunch 的旧控制台或安装器。

## 来源与视觉约束

![2013 DDE reference](../assets/dde-2013-reference.png)

用户明确指定从这张截图拆分底栏。该图为设计参考，非 XDock 的实现截图。

保留底部贴边的轻薄深色透明条、密集且大小一致的彩色图标，以及应用区与右侧系统区的分隔。沿用 XLaunch 的琥珀色环境，不扩展为高大的悬浮玻璃卡片。原图桌面为 600×450；不能直接把其像素高度当成现代逻辑像素规格。

待原型验证的初始尺寸：底栏 44–56 逻辑像素、图标 32–40、紧凑间距。采用真实应用图标；背景不支持模糊时降级为透明或不透明深色。支持减少动画、可见键盘焦点和更大图标。当前不假定实现放大鱼眼动画。

## 核心行为

- 固定区：打开应用；运行中显示轻量标记；拖动排序，菜单固定或取消固定。
- 运行区：未固定但正在运行的应用临时出现；退出后移除。
- 窗口切换：单窗口激活，多窗口显示可选择列表；无权限或不支持时明确降级。
- XLaunch 入口：安装后可固定为普通入口；未安装时 Dock 仍正常使用。
- 显隐：可选择常驻或自动隐藏，需验证多显示器、屏幕边缘和全屏窗口行为。
- 系统区：时间、音量、网络和托盘作为可选平台能力；不将全套系统区作为核心依赖。不可用时隐藏或转交宿主面板。

## 核心与适配层

公共核心管理固定顺序、应用身份、运行状态模型、配置及交互。平台适配层提供应用发现、进程与窗口状态、激活、屏幕布局、保留边缘空间、焦点、托盘及系统动作。

目标：macOS 26+、GNOME 50、KDE Plasma 6.6、DDE 7.0、Xfce。全部为计划状态，尚未验证 API。不同桌面对窗口枚举、控制、置顶和托盘有不同能力，不能承诺一个通用协议覆盖所有目标。

宿主原生 Dock/面板的保留、隐藏或替换由用户配置，安装 XDock 不自动移除。macOS 的原生 Dock 共存策略、Linux 不同会话的窗口管理能力，均为原型后技术验证事项。

## 与 XLaunch 的可选契约

应用 ID、图标来源与启动请求可复用统一的数据约定；各仓库以版本化接口交互。XDock 点击 XLaunch 入口可请求显示或隐藏启动器。双方退出或未安装时，另一方保持可用。IPC 技术和共享库的发布方式尚未决定。

## 验收顺序

1. 独立 Dock 设计：空闲、悬停、运行标记、多窗口、溢出、自动隐藏。
2. 选一个目标桌面验证真实应用启动、窗口激活和屏幕边缘行为。
3. 完成可交互原型，并清楚区分模拟与真实能力。
4. 扩展其余适配层，逐项记录已支持、降级和不支持能力。
